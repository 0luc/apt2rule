apt2rule

Pick the APT groups from your threat analysis. apt2rule finds the ATT&CK techniques they use and the Elastic prebuilt detection rules that cover them, and gives you a Kibana Dev Tools snippet that only adds tags. Then filter by tag in Kibana and bulk-enable or bulk-disable. Everything runs in your browser; nothing you select leaves it.

1. Profile

Profiles are saved in this browser only. Export them to back them up or share them.

2. APT groups

    Selected (0)

      3. Techniques

      Untick a technique to exclude it, or tick one below the threshold to include it anyway.

      4. Filter rules by tag

      The same tags you see in Kibana's rules table. Within a category a rule needs any ticked tag; across categories it needs all of them. E.g. Data Source: Elastic Defend + OS: Linux + OS: Windows keeps Elastic Defend rules for Linux or Windows. Nothing ticked means no filter.

        5. Output

          1. In Kibana, install all Elastic prebuilt rules (Rules > Add Elastic rules). They install disabled. Make sure the ruleset version above is the one installed: only rules in that version get tagged.
          2. Open Dev Tools, paste the snippet and run the dry run requests. Compare the counts with the comments.
          3. Run the apply requests. They only add tags; no rule is changed, enabled or disabled.
          4. In the rules table, filter by tag and bulk-enable () or bulk-disable () after review.

          Tagging a prebuilt rule marks it as customised in Kibana, and rule upgrades may drop the tags. Re-run apt2rule after upgrading rules.
