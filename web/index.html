apt2rule

Threat profile → Elastic detection coverage

  • MITRE ATT&CK®
  • Elastic Security
  • Runs in your browser

Select the APT groups from your threat analysis. apt2rule maps the ATT&CK techniques they use to Elastic prebuilt detection rules and gives you a Kibana Dev Tools snippet that only adds tags. Filter by tag in Kibana to bulk-enable or bulk-disable. Nothing you select leaves your browser.

Disclaimer. This product is fully vibe coded (built with AI assistance) and comes with no guarantees. Always run the dry run and review the rules before enabling or disabling anything in your cluster.

01 Profile and ruleset

Profiles are saved in this browser only. Export them to back them up or share them.

Which ruleset version is installed in my Kibana?
  1. In Kibana, open Management → Integrations, search for Prebuilt Security Detection Rules and open its Settings tab. It shows the installed version, e.g. 9.5.9.
  2. Or run this in Dev Tools and look for installationInfo.version in the response (older Kibana: savedObject.attributes.version): 
    GET kbn:/api/fleet/epm/packages/security_detection_engine

apt2rule offers the newest ruleset for each Kibana version. If yours is an older patch, update the prebuilt rules in Kibana (Rules → Update) or expect small differences in the dry-run counts.

      03 Techniques

      Untick a technique to exclude it, or tick one below the threshold to include it anyway.

      04 Filter rules by tag

      The same tags you see in Kibana's rules table. Within a category a rule needs any ticked tag; across categories it needs all of them. E.g. Data Source: Elastic Defend + OS: Linux + OS: Windows keeps Elastic Defend rules for Linux or Windows. Nothing ticked means no filter.

        05 Output

          Dry run changes nothing. Paste it into Kibana Dev Tools and compare each response's count with the comments. Install all Elastic prebuilt rules first (Rules → Add Elastic rules); they install disabled.

          Production adds the tags. It never changes, enables or disables a rule. Afterwards, filter the rules table on to bulk-enable, and review to bulk-disable. Tagged prebuilt rules count as customised in Kibana, and rule upgrades may drop the tags: re-run after upgrading.
